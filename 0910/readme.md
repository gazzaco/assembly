안녕하십니까. MASM에 대해 발표할 황주은 입니다.
*
먼저 MASM이 무엇인지 알아보겠습니다.
MASM은 마이크로소프트가 만든 어셈블러 프로그램 입니다. 여기서 어셈블러란 어셈블리어 코드를 컴퓨터가 읽고, 실행할 수 있도록 기계어로 변환해주는 프로그램입니다.

저희가 이번에 예제 문제를 풀며 사용해볼 어셈블러는 32비트입니다. 64비트는 현대의 표준이긴하지만, 어셈블리어의 핵심 개념을 배우기에는 불필요하게 복잡하고 제약이 많기 때문에 처음에는 32비트로 공부하는게 학습 효율이 좋습니다.
*
MASM이 어셈블러 라는것을 알게되었으니, 이제는 이 어셈블러가 어떻게 작동하는지에 대해 알아보겠습니다.

일단 먼저 어셈블리어 코드를 작성합니다.
그러면 어셈블러가 저희가 작성한 어셈블리어 코드를 기계어로 번역을 해서 목적파일을 만들어주고 이 과정을 어셈블링이라고 부릅니다.
이 목적파일 혼자서는 프로그램을 실행할 수 없기 때문에, 실행에 필요한 함수가 내포되어있는 라이브러리와 목적파일을 합쳐서 최종 실행 파일을 만들어 줍니다. 이를 링킹이라고 합니다.
이렇게 나온 실행파일은 0과 1로 이루어진 기계어가 되고, 운영체제가 이걸 바로 읽어서 실행하게 됩니다.

이제 직접 어셈블리어를 써보는 실습 방법을 안내해 드리겠습니다.

-

먼저 MASM 공식 페이지에서 다운로드를 하고 설치를 진행하면 C드라이브에 masm32라는 폴더가 생성됩니다.
-

코드작성은 메모장에서 하고 이 메모장의 저장 장소는 방금의 masm32 입니다.

제가 하나하나 다 설명을 해드릴게요 ㅎㅎ

먼저 첫 코드는 MASM의 표준 헤더 파일 입니다.
다들 c언어 배우셨을텐데 c에서 #include 어쩌구 를 써야 printf를 쓸 수 있는 것과 똑같은 의미입니다.

.data는 초기값이 있는 데이터 영역의 시작 표시입니다.

그 안의 내용을 한번 보겠습니다. 먼저 이 데이터의 주소에 붙은 이름은 m1, 옆의 db는 define byte로 1바이트씩 메모리를 채우겠다 라는 의미입니다. 그리고 hello world를 m1에 저장합니다. 13, 10은 줄바꿈을 의미하고 마지막의 0은 문자열의 끝을 표시합니다.

밑에 코드를 보시면 아까와 같은 방식인데 13, 10 즉 줄바꿈이 없죠. 이건 나중에 덧셈 식을 출력하고 계산의 결과값을 그 뒤에 이어 붙이기 위해서 줄바꿈을 뺐습니다.

다음줄의 nl은 글자없이 줄바꿈만 들어있는 문자열 입니다.

.data물음표는 값을 정해두지 않은 데이터 영역이고 계산 결과를 담을 r을 만들어 두었습니다. dd는 define doubleword로 4바이트 크기입니다.

여기서 4바이트 크기 를 쓴 이유는 뒤에서 계산에 쓸 eax 레지스터가 4바이트이기 때문에 크기를 맞춘것 입니다.

.code 여기서부터가 실제로 실행되는 기계어 명령이라는 표시입니다.

start는 코드 끝에있는 end start와 둘이 같이 각각 프로그램 시작지점과 끝지점을 의미합니다.

오프셋 엠원 은 데이터의 주소를 의미합니다. m1(엠원)의 값은 hello world 이니 hello world가 출력이 되겠죠..

다음 줄 보시겠습니다. move는 오른쪽의 값을 왼쪽에 복사하는 명령입니다. 그러면 3을 eax에 넣겠다는 의미져
여기서 eax는 산술연산 레지스터 입니다.

eax에 2를 더하고 eax의 값을 r에 저장합니다.
아까 위에서 정의했던 m2를 출력하고 r에 든 숫자를 프린트 한 뒤 줄바꿈까지 해줍니다.

뒤의 코드 또한 비슷한데 다른점 이라면 뺄셈을 하기 위해 sub을 사용했습니다.

자 이제 코드 작성이 다 끝났습니다!
---

코드 작성을 다 하면, 저장을 해야하는데 이 때 메모장의 파일이름을 .asm으로 저장하고 파일형식을 모든 파일로 바꿔야 합니다.

아까 다운받았던 masm32 파일에 bin이라는 폴더에 들어가보시면 어셈블러와 링커가 있습니다.

저희는 이것을 사용해서 소스코드를 오브젝트 파일과 실행파일로 변환해야 합니다.

먼저 cmd를 열어 작업위치인 MASM32로 이동합니다.
그리고 어셈블리어 코드를 어셈블링을 통해 오브젝트 파일로 바꿔줍니다.
이 작업이 끝나고 MASM32 폴더를 찾아보시면 오브젝트 파일이 생성된 걸 확인할 수 있습니다.

그리고 링커를 이용하여 오브젝트파일과 라이브러리 함수들을 링킹해서 실행파일을 생성합니다.

이제 cmd 창에서 생성된 실행파일을 출력해 보았을 때 결과가 모두 잘 나오는걸 볼 수 있습니다.

자 이런식으로 어셈블리어 코드가 어떻게 실행가능한 파일이 되는지의 과정과 어셈블리어의 기초에 대해 알아보았습니다. 제가 만든 피피티는 단톡방에 공유해 드릴테니 학우분들께서 따라해보시면 좋을거 같습니다. 
이상으로 발표를 마치겠습니다. 감사합니다.
