정적 라이브러리는 컴파일 시점에서 링크되고, 동적 라이브러리는 실행 시점에서 링크됨.

그래서 실행 파일 크기가 정적방식은 크고, 동적 방식은 라이브러리 참조 정보만 포함되기 때문에 작다

이후 라이브러리가 바뀌면 정적방식은 전체 프로그램을 다시 컴파일 해야하고, 동적은 라이브러리 파일만 교체하면 됨.
