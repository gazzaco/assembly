# 🖥️ 컴퓨터 구조: 레지스터(Register)의 종류와 역할

**레지스터(Register)**는 CPU 내부에 존재하는 가장 빠르고 작은 임시 기억 장치입니다. CPU가 연산을 수행하는 데 필요한 데이터나 명령어, 메모리 주소 등을 일시적으로 저장하는 핵심적인 역할을 합니다.

---

## 1. 특수 목적 레지스터 (Special Purpose Register)
CPU가 작동하기 위해 특정 기능만을 수행하도록 설계된 아주 중요한 레지스터들입니다. (전공 면접 및 시험 필수 개념)

| 레지스터 명칭 | 약자 | 역할 | 특징 |
|---|:---:|---|---|
| **Program Counter**<br>(프로그램 카운터) | `PC` / `IP` | **다음에 실행할 명령어의 메모리 주소**를 저장 | 명령어가 하나 실행될 때마다 자동으로 다음 주소로 증가 |
| **Instruction Register**<br>(명령어 레지스터) | `IR` | **현재 실행 중인 명령어**를 기억 | 메모리에서 명령어를 가져와(Fetch) 저장한 후 해독(Decode)하여 실행 |
| **Memory Address Register**<br>(메모리 주소 레지스터) | `MAR` | 읽거나 쓸 **메모리의 주소**를 임시로 저장 | PC나 다른 레지스터에 있는 주소가 메모리로 가기 전 반드시 거침 |
| **Memory Buffer Register**<br>(메모리 버퍼 레지스터) | `MBR` / `MDR` | 메모리에서 읽어온/쓸 **데이터**를 임시로 저장 | MAR을 통해 찾은 주소의 데이터가 이곳으로 이동 |
| **Stack Pointer**<br>(스택 포인터) | `SP` | 메모리 스택 영역에서 **최상단 주소**를 지칭 | 함수 호출 시 돌아갈 주소나 지역 변수 관리에 사용 |

---

## 2. 상태 및 제어 레지스터 (Status / Control Register)
CPU의 현재 상태나 연산 결과의 상태를 나타내는 레지스터입니다.

### 📌 플래그 레지스터 (Flag Register) / PSW (Program Status Word)
- **역할:** 산술 논리 연산 장치(ALU)의 연산 결과에 따른 **CPU의 현재 상태**를 저장합니다.

**[주요 플래그 종류]**
| 플래그 이름 | 약자 | 설명 |
|---|:---:|---|
| **Zero Flag** | `ZF` | 연산 결과가 0일 때 1이 됨 (조건문에서 두 값이 같은지 비교할 때 주로 사용) |
| **Sign Flag** | `SF` | 연산 결과가 음수일 때 1이 됨 |
| **Overflow Flag** | `OF` | 연산 결과가 레지스터의 용량을 초과했을 때(오버플로우 발생) 1이 됨 |
| **Carry Flag** | `CF` | 덧셈이나 뺄셈에서 최상위 비트의 자리 올림/내림이 발생했을 때 1이 됨 |

---

## 3. 범용 레지스터 (General Purpose Register)
이름 그대로 특정 목적이 정해져 있지 않고, 프로그래머가 연산 데이터나 주소 등을 자유롭게 저장할 수 있는 레지스터입니다. *(아래는 x86 아키텍처 기준)*

| 레지스터 명칭 | 약자 (32/64bit) | 주요 역할 |
|---|:---:|---|
| **Accumulator Register** | `EAX` / `RAX` | 주로 산술 연산의 결과를 저장하거나, 함수의 반환값을 저장 |
| **Base Register** | `EBX` / `RBX` | 메모리 주소(Base Address)를 저장하는 데 자주 사용 |
| **Count Register** | `ECX` / `RCX` | 반복문(Loop)을 실행할 때 반복 횟수를 카운트 |
| **Data Register** | `EDX` / `RDX` | 큰 수의 곱셈/나눗셈 시 EAX와 함께 데이터를 저장하거나 입출력 포트 주소 지정 |

---

## 4. 기타 레지스터

| 레지스터 명칭 | 설명 |
|---|---|
| **세그먼트 레지스터<br>(Segment Register)** | 메모리를 여러 구역(코드, 데이터, 스택 등)으로 나누어 관리할 때, 각 구역의 시작 주소를 저장 (`CS`, `DS`, `SS` 등) |
| **부동소수점 레지스터<br>(Floating-Point Register)** | 소수점이 있는 실수 연산을 고속으로 처리하기 위해 사용되는 전용 레지스터 |
