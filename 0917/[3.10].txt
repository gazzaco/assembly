3.10 Programming Exercises (프로그래밍 연습문제)

★ 1. Integer Expression Calculation (정수 수식 계산)
- 번역: 섹션 3.2의 AddTwo 프로그램을 참고하여, 레지스터를 사용하여 다음 수식을 계산하는 프로그램을 작성하시오: $Rval = (A + B) - (C + D)$. EAX, EBX, ECX, EDX 레지스터에 각각 정수 값을 할당하시오.
- 정답 / 모범 답안:
  ```assembly
  .data
  ; (필요시 변수 정의 가능, 레지스터 위주로 풀이)
  .code
  main PROC
      mov eax, 10      ; A = 10
      mov ebx, 20      ; B = 20
      mov ecx, 5       ; C = 5
      mov edx, 2       ; D = 2

      add eax, ebx     ; eax = A + B (30)
      add ecx, edx     ; ecx = C + D (7)
      sub eax, ecx     ; eax = (A + B) - (C + D) -> 23
      
      call DumpRegs
      exit
  main ENDP
  ```

★ 2. Symbolic Integer Constants (심볼릭 정수 상수)
- 번역: 일주일의 7일 모두에 대해 심볼릭 상수를 정의하는 프로그램을 작성하시오. 이 심볼들을 초기화 값으로 사용하는 배열 변수를 생성하시오.
- 정답 / 모범 답안:
  ```assembly
  .data
  Monday    EQU 1
  Tuesday   EQU 2
  Wednesday EQU 3
  Thursday  EQU 4
  Friday    EQU 5
  Saturday  EQU 6
  Sunday    EQU 7

  weekDays DWORD Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday
  ```

★★ 3. Data Definitions (데이터 정의)
- 번역: 섹션 3.4의 표 3-2에 나열된 각 데이터 타입의 정의가 포함된 프로그램을 작성하시오. 각 변수를 해당 데이터 타입에 일치하는 값으로 초기화하시오.
- 정답 / 모범 답안:
  ```assembly
  .data
  val1 BYTE  10h
  val2 SBYTE -10
  val3 WORD  2000h
  val4 SWORD -2000
  val5 DWORD 12345678h
  val6 SDWORD -12345678
  val7 QWORD 123456789ABCDEF0h
  val8 TBYTE 123456789ABCDEF01234h
  ```

★ 4. Symbolic Text Constants (심볼릭 텍스트 상수)
- 번역: 여러 개의 문자열 리터럴(따옴표 안의 문자들)에 대한 심볼릭 이름을 정의하는 프로그램을 작성하시오. 변수 정의에서 각 심볼릭 이름을 사용하시오.
- 정답 / 모범 답안:
  ```assembly
  .data
  Greeting TEXTEQU <"Hello, World!", 0>
  Prompt   TEXTEQU <"Enter a number: ", 0>

  str1 BYTE Greeting
  str2 BYTE Prompt
  ```

★★★★ 5. Listing File for AddTwoSum (AddTwoSum 리스팅 파일)
- 번역: AddTwoSum 프로그램에 대한 리스팅 파일을 생성하고, 각 명령어에 대해 생성된 기계어 바이트에 대한 설명을 작성하시오. 바이트 값의 의미 중 일부는 추측해야 할 수도 있습니다.
- 정답 / 모범 답안:
  - 설명: MASM에서 리스팅 파일(`.lst`)을 생성하면 각 어셈블리 명령어에 대응하는 기계어(Machine Code)의 오프셋과 바이트 값들이 16진수로 표시됩니다. 예를 들어 `mov eax, 5` 같은 명령어는 오프셋 주소, 기계어 Opcode 바이트(예: `B8 00000005`), 그리고 원본 소스 라인이 함께 출력됩니다. 레지스터가 포함된 명령어인지, 메모리 주소가 포함된 것인지에 따라 ModR/M 바이트 등이 결합되는 방식을 리스팅 파일을 통해 확인할 수 있습니다.

★★★ 6. AddVariables Program (AddVariables 프로그램 수정)
- 번역: AddVariables 프로그램을 64비트 변수를 사용하도록 수정하시오. 어셈블러가 발생시킨 구문 오류와 오류를 해결하기 위해 취한 조치들을 설명하시오.
- 정답 / 모범 답안:
  - 설명: 32비트 모드(MASM)에서 64비트 정수 연산(`QWORD`)을 수행할 때는 32비트 레지스터가 32비트 크기이므로 64비트 데이터를 한 번에 통째로 레지스터에 담아 연산할 수 없습니다. 따라서 `ADD`나 `SUB` 연산을 수행할 때 상위 32비트와 하위 32비트를 나누어 처리(예: `adc`, `add` 조합 등 다중 정밀도 연산)해야 합니다. 64비트 변수를 선언(`QWORD`)한 뒤 32비트 레지스터에 직접 `mov eax, valQ` 형식으로 넣으려 하면 크기 불일치(Type mismatch) 구문 오류가 발생하므로, 각각의 하위/상위 파트를 나누어 접근하거나 64비트 컴파일 환경(ml64.exe)을 사용해야 오류가 해결됩니다.
