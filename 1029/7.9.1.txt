6. 다음 연산이 실행된 후 AX와 DX의 값은 무엇인가?

[정답]
AX = 0000h

9. 다음 프로그램은 val1에서 val2를 빼는 프로그램이다. 모든 논리 오류를 찾아 수정하시오. (CLC는 Carry 플래그를 지움)
[코드]
.data
val1 QWORD 20403004362047A1h
val2 QWORD 055210304A2630B2h
result QWORD 0

.code
mov cx, 8 ; loop counter
mov esi, val1 ; set index to start
mov edi, val2
clc ; clear Carry flag
top:
mov al, BYTE PTR[esi] ; get first number
sbb al, BYTE PTR[edi] ; subtract second
mov BYTE PTR[esi], al ; store the result
dec esi
dec edi
loop top

[정답]
수정된 코드:
.data
val1 QWORD 20403004362047A1h
val2 QWORD 055210304A2630B2h
result QWORD 0

.code
mov cx, 8
mov esi, OFFSET val1
mov edi, OFFSET val2
clc
top:
mov al, BYTE PTR[esi]
sbb al, BYTE PTR[edi]
mov BYTE PTR[esi], al
inc esi
inc edi
loop top

오류 내용:
1. `mov esi, val1` 및 `mov edi, val2`를 `mov esi, OFFSET val1`, `mov edi, OFFSET val2`로 수정해야 함 (주소 복사).
2. `dec esi`, `dec edi`를 `inc esi`, `inc edi`로 수정해야 함 (리틀 엔디안 방식에 따라 최하위 바이트부터 시작하여 증가).
