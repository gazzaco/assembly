## pc(프로그램 카운터)
- 중앙처리장치(CPU) 내부에 있는 레지스터 중 하나로, 다음에 실행할 명령어의 메모리 주소를 저장하는 역할

1. 주요 특징 및 기능

• 명령어 포인터(IP): 일부 아키텍처(예: 인텔 x86 등)에서는 프로그램 카운터를 명령어 포인터(Instruction Pointer, IP)라고 부르기도 합니다.

• 순차적 실행: CPU가 메모리에서 명령어를 하나씩 읽어올 때마다(Fetch), 프로그램 카운터의 값은 자동으로 증가(예: 명령어의 크기나 1만큼 증가)하여 다음 순서의 명령어를 가리킵니다.

• 비순차적 변경: 조건문(if), 반복문(loop), 점프문(jump) 또는 함수 호출 등이 발생할 때는 프로그램 카운터 값이 순차적이 아닌 특정 분기(Target) 주소로 직접 변경되어 흐름이 바뀝니다.


## SP(스택 포인터)
- 스택은 함수 호출 시 반환 주소, 저장 레지스터 값, 지역 변수 및 임시 데이터를 보관하는 LIFO 메모리 영역이다. SP는 현재 스택의 최상단을 가리키는 레지스터
