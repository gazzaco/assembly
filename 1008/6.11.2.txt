[6.11.2 Exercise Descriptions]

1. 배열 채우기 (Filling an Array)
   - 설명: N개의 랜덤 정수로 더블워드 배열을 채우는 프로시저를 생성하시오. 값은 j부터 k 사이(포함)의 범위여야 합니다. 프로시저 호출 시 데이터를 담을 배열의 포인터, N, 그리고 j와 k의 값을 전달하십시오. 호출 간에 모든 레지스터 값을 보존하고, j와 k에 다른 값을 사용하여 프로시저를 두 번 호출하는 테스트 프로그램을 작성하십시오.

2. 범위 내 배열 요소 합산 (Summing Array Elements in a Range)
   - 설명: j부터 k 사이(포함)에 속하는 모든 배열 요소의 합을 반환하는 프로시저를 생성하시오. 부호 있는 더블워드 배열의 포인터, 배열의 크기, j와 k의 값을 전달하여 프로시저를 두 번 호출하는 테스트 프로그램을 작성하십시오. 합은 EAX 레지스터로 반환하고 다른 모든 레지스터는 보존하십시오.

3. 시험 점수 평가 (Test Score Evaluation)
   - 설명: CalcGrade라는 이름의 프로시저를 만드시오. 0과 100 사이의 정수 값을 받아 AL 레지스터에 대문자 학점 문자('A', 'B', 'C', 'D', 'F')를 반환합니다. (점수 구간: 90~100: A, 80~89: B, 70~79: C, 60~69: D, 0~59: F). 50에서 100 사이의 임의의 정수 10개를 생성하여 각 점수를 CalcGrade에 전달하는 테스트 프로그램을 작성하십시오.

4. 대학 등록 (College Registration)
   - 설명: 섹션 6.7.3의 College Registration 예제를 바탕으로 .IF/.ELSEIF 지시어 대신 CMP와 조건부 점프 명령어로 로직을 재작성하고, 학점 값이 1 미만거나 30을 초과하지 않는지 범위 검사(range checking)를 수행하십시오.

5. 불리언 계산기 (1) (Boolean Calculator 1)
   - 설명: 32비트 정수를 위한 간단한 불리언 계산기로 동작하는 프로그램을 만드시오. 메뉴(1. x AND y, 2. x OR y, 3. NOT x, 4. x XOR y, 5. Exit program)를 표시하고 사용자의 선택에 따라 테이블 기반 선택 기법(Table-Driven Selection technique)을 사용하여 연산 이름을 표시하는 프로시저를 호출하십시오.

6. 불리언 계산기 (2) (Boolean Calculator 2)
   - 설명: 연습문제 5의 솔루션 프로그램을 이어받아 다음 프로시저들(AND_op, OR_op, NOT_op, XOR_op)을 구현하여 16진수 정수 연산 및 결과 출력을 수행하도록 하시오.

7. 확률과 색상 (Probabilities and Colors)
   - 설명: 화면에 텍스트를 표시할 때 세 가지 다른 색상(화이트=30%, 블루=10%, 그린=60%) 중 하나를 무작위로 선택하는 프로그램을 작성하시오. 루프를 사용하여 무작위 색상으로 20줄의 텍스트를 출력하십시오.

8. 메시지 암호화 (Message Encryption)
   - 설명: 섹션 6.3.4의 암호화 프로그램을 수정하여 여러 문자로 구성된 암호화 키를 생성하고, XOR 연산을 통해 평문과 키를 반복하여 암호화/복호화하는 프로그램을 만드시오.

9. PIN 유효성 검증 (Validating A PIN)
   - 설명: 5자리 PIN이 포함된 바이트 배열의 포인터를 받는 `Validate_PIN` 프로시저를 생성하시오. 최솟값과 최댓값 범위를 저장할 두 개의 배열을 선언하고, 이 배열을 사용하여 전달된 PIN의 각 자릿수를 검증하십시오. 어떤 자릿수가 유효 범위를 벗어나면, EAX 레지스터에 해당 자릿수의 위치(1에서 5 사이)를 즉시 반환하십시오. 전체 PIN이 유효하면 EAX에 0을 반환하십시오. 호출 간에 다른 모든 레지스터 값을 보존하고, 유효한 바이트 배열과 유효하지 않은 바이트 배열을 모두 사용하여 최소 네 번 `Validate_PIN`을 호출하는 테스트 프로그램을 작성하십시오.

10. 패리티 검사 (Parity Checking)
    - 설명: 데이터 전송 시스템과 파일 서브시스템은 데이터 블록의 패리티(짝수 또는 홀수) 계산에 의존하는 오류 검출 형태를 자주 사용합니다. 배열의 바이트들이 짝수 패리티를 포함하면 EAX 레지스터에 True(1)를 반환하고, 홀수 패리티이면 False(0)를 반환하는 프로시저를 생성하시오. 즉, 전체 배열의 모든 비트를 카운트했을 때 그 개수가 짝수인지 홀수인지 판별합니다. 호출 간에 다른 모든 레지스터 값을 보존하고, 배열의 포인터와 배열의 길이를 전달하여 프로시저를 두 번 호출하는 테스트 프로그램을 작성하십시오. 테스트 데이터로는 최소 10바이트를 포함하는 두 개의 배열(하나는 짝수 패리티, 다른 하나는 홀수 패리티)을 생성하십시오.
