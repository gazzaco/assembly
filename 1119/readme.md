## 2. 핵심 개념 요약

### 구조체 (Structures)
* **`STRUCT` / `ENDS`:** 서로 다른 자료형의 필드를 묶어 사용자 정의 복합 데이터 타입을 선언합니다.
* **구조체 변수 초기화:** 꺾쇠괄호 `<...>`를 사용해 필드 값을 순서대로 초기화하며, 생략한 필드는 기본값 또는 정의된 초기값을 사용합니다.
* **중첩 구조체와 배열:** 구조체 안에 다른 구조체(`COORD` 등)나 배열 필드를 포함할 수 있으며, 구조체 배열을 선언해 오프셋/인덱스로 접근합니다.
* **Win32 API 구조체:** `SYSTEMTIME`, `COORD` 등 Windows 콘솔 및 시스템 호출에서 사용하는 구조체 필드를 다룹니다.

### 매크로 (Macros)
* **`MACRO` / `ENDM`:** 반복되는 코드 패턴이나 파라미터화된 명령 시퀀스를 어셈블 타임에 치환하여 확장합니다.
* **`LOCAL`:** 매크로가 여러 번 확장될 때 내부 점프 레이블(`@@`, 고유 로컬 이름) 충돌을 방지합니다.
* **매크로 연산자:**
  * `&` (Substitution / 치환): 매크로 파라미터를 문자열 리터럴이나 식별자 일부와 결합할 때 사용합니다.
  * `!` (Literal escape / 리터럴 이스케이프): `<`, `>`, `,`, `;` 등 특수문자를 구분자가 아닌 일반 문자로 전달할 때 사용합니다.
  * `%` (Expression / 표현식 평가): 상수 표현식을 먼저 계산한 뒤 그 결과 값을 인수로 전달할 때 사용합니다.
* **매크로 라이브러리 활용:** `mWrite`, `mWriteStr`, `mReadStr`, `mGotoxy`, `mDumpMem` 등 라이브러리 매크로를 래핑하거나 확장해 입출력 및 디버깅 매크로를 구성합니다.

### 조건부 어셈블리 (Conditional Assembly)
* **`IF` / `ELSE` / `ENDIF`:** 어셈블 타임 상수 조건에 따라 포함할 코드 블록을 선택합니다.
* **관계 연산자:** `LT`, `LE`, `GT`, `GE`, `EQ`, `NE` 등을 사용해 매크로 인수의 유효성 검사나 피연산자 크기에 따른 분기 처리를 수행합니다.
* **`EXITM`:** 매크로 확장 과정에서 조건 불만족 시 확장을 즉시 중단하고 빠져나옵니다.

## 3. 프로그래밍 연습(10.8절) 주요 구현 항목

* **입출력 및 메모리 조작 매크로:** `mReadkey`, `mWritestringAttr`, `mMove32`, `mMult32`, `mReadInt`, `mWriteInt`
* **확률/시뮬레이션 실습:** 드렁커드 워크(Drunkard's Walk)에서의 휴대폰 분실 시점 구현 및 방향별 이동 확률 조정
* **다중 더블워드 시프트:** `SHLD`, `SHRD`를 활용한 좌/우 비트 시프트 매크로 (`mShiftDoublewords`)
* **3-피연산자 산술 매크로:** `add3`, `sub3`, `mul3`, `div3` 구현 및 복합 수식 테스트
