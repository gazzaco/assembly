정답:
mPrintChar MACRO char, count
    LOCAL L1
    push eax
    push ecx
    mov al, char
    mov ecx, count
L1:
    call WriteChar
    loop L1
    pop ecx
    pop eax
ENDM

16. 다음과 같은 mLocate 매크로 정의를 가정하자:
mLocate MACRO xval,yval
    IF xval LT 0        ;; xval < 0?
        EXITM           ;; if so, exit
    ENDIF
    IF yval LT 0        ;; yval < 0?
        EXITM           ;; if so, exit
    ENDIF
    mov bx,0            ;; video page 0
    mov ah,2            ;; locate cursor
    mov dh,yval
    mov dl,xval
    int 10h             ;; call the BIOS
ENDM

다음 각 명령문에 의해 매크로가 확장될 때 전처리기가 생성하는 소스 코드를 보이시오:
.data
row BYTE 15
col BYTE 60
.code
mLocate -2,20
mLocate 10,20
mLocate col,row

정답:
1) mLocate -2,20 의 확장 결과:
(아무 코드도 생성되지 않음. xval(-2)이 0보다 작으므로 EXITM에 의해 매크로 확장이 즉시 종료됨)

2) mLocate 10,20 의 확장 결과:
    mov bx,0
    mov ah,2
    mov dh,20
    mov dl,10
    int 10h

3) mLocate col,row 의 확장 결과:
(주의: 어셈블 시점에 col과 row는 상수가 아닌 메모리 변수이므로 상수 불리언 표현식 `IF col LT 0`에서 어셈블러 오류(A2026: constant expected)가 발생한다. 만약 오류 없이 확장된다고 가정하면 아래와 같은 코드가 생성된다.)
    mov bx,0
    mov ah,2
    mov dh,row
    mov dl,col
    int 10h
